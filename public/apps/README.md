# Ярлычки приложений (иконки рабочего стола)

Сюда кладём картинки-иконки приложений платформы. Имя файла задаётся полем
`iconUrl` в `src/config/apps.js` и должно точно совпадать.

Ожидаемые файлы (имя = `id` приложения из `apps.js`):

| Приложение     | id        | Файл                  |
|----------------|-----------|-----------------------|
| СИЗ-контроль   | `siz`     | `/apps/siz.png`       |
| Склад          | `sklad`   | `/apps/sklad.png`     |
| Отчёты         | `reports` | `/apps/reports.png`   |
| Светлячок      | `svet`    | `/apps/svet.png`      |

Требования к картинкам:
- Формат **PNG** (или SVG — тогда меняем расширение в `iconUrl` на `.svg`).
- Квадратные, лучше **256×256** (отрисовываются в 28px на столе и 24px в доке,
  `object-fit: contain`).
- Прозрачный фон желателен.

Файлы из этой папки Vite отдаёт по пути `/apps/<файл>` без изменений.
Если файла нет — на столе покажется запасная lucide-иконка (поле `icon`),
интерфейс не сломается.
