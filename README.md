# Платформа — оболочка (web-desktop)

Браузерный «рабочий стол»: единый вход, иконки приложений, окна, которые
можно перетаскивать и менять в размере. Каждое приложение открывается в
окне через `iframe` и остаётся отдельным сервисом — оболочка их только
собирает воедино.

Стек: React + Vite, `react-rnd` (окна), `zustand` (состояние),
`keycloak-js` (вход), `lucide-react` (иконки).

---

## Структура

```
src/
  theme/
    tokens.css      ← ЕДИНЫЙ файл стилей (цвета, отступы, шрифты). Меняй его.
    app.css         ← вёрстка/раскладка, ссылается только на токены
  auth/
    keycloak.js     ← конфиг Keycloak + dev-режим без него
    AuthProvider.jsx← провайдер авторизации (даёт user, login, logout)
    useAuth.js      ← хук useAuth()
  config/
    apps.js         ← РЕЕСТР приложений (добавляешь приложения здесь)
  store/
    useDesktopStore.js ← менеджер окон и уведомлений
  components/
    LoginScreen.jsx    ← экран входа
    Desktop.jsx        ← рабочий стол (панель + иконки + окна + док)
    TopBar.jsx         ← верхняя панель (часы, уведомления, выход)
    Dock.jsx           ← нижний док
    WindowFrame.jsx    ← окно (перетаскивание/ресайз)
    AppFrame.jsx       ← iframe приложения + передача токена
    NotificationCenter.jsx ← колокольчик и панель уведомлений
    Clock.jsx
Dockerfile, nginx.conf, amvera.yml ← деплой на Amvera
docs/siz-integration-prompt.md     ← промт для Claude Code под СИЗ-контроль
```

## Запуск локально

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`. По умолчанию включён режим
`VITE_AUTH_DISABLED=true` (файл `.env`) — заходишь без Keycloak под
тестовым пользователем и сразу видишь интерфейс.

В панели справа есть колокольчик; в dev-режиме внутри него кнопка
«+ тестовое уведомление», чтобы проверить, как они приходят.

## Как менять внешний вид

**Весь внешний вид задаётся одним файлом — `src/theme/tokens.css`.**
Там лежат все цвета, отступы, скругления, тени и шрифты в виде
CSS-переменных. Компоненты собственных цветов не содержат.

Чтобы перекрасить платформу через **Claude Designer** — открой ему
`src/theme/tokens.css` и попроси поменять палитру/скругления/шрифты,
правя только значения переменных. Имена переменных менять не нужно —
тогда ничего не сломается.

Тёмная тема уже заложена: блок `[data-theme="dark"]` в том же файле.
Включить — `document.documentElement.setAttribute('data-theme','dark')`.

## Как добавить приложение

В `src/config/apps.js` добавь объект в массив `APPS`:

```js
{
  id: 'tabel',
  name: 'Табель',
  icon: Clock,                         // любая иконка из lucide-react
  url: import.meta.env.VITE_APP_TABEL_URL,
  roles: ['hr', 'admin'],              // [] = видно всем
  window: { width: 1000, height: 680 },
}
```

`roles` — это фильтр **только для интерфейса** (какие иконки показывать).
Реальную проверку прав обязано делать само приложение на своём бэкенде.

## Авторизация

- Оболочка логинит пользователя через Keycloak и получает JWT.
- Из токена берутся: `sub` (постоянный id), `email`, `name`, роли
  (`realm_access.roles`).
- При открытии приложения в окне токен передаётся внутрь `iframe`
  через `postMessage` сообщением `{ type: 'platform-auth', token }`.

Подключение реального Keycloak:

1. Подними Keycloak (на Amvera он есть в маркетплейсе, в один клик).
2. Создай realm (напр. `platform`) и клиента `web-desktop`
   (тип public, Standard flow, в Redirect URIs — адрес оболочки).
3. Пропиши в `.env.production` (можно коммитить, это не секреты):
   ```
   VITE_AUTH_DISABLED=false
   VITE_KEYCLOAK_URL=https://auth.platform.ru
   VITE_KEYCLOAK_REALM=platform
   VITE_KEYCLOAK_CLIENT=web-desktop
   VITE_APP_SIZ_URL=https://siz.platform.ru
   ```

> Переменные `VITE_*` вшиваются на этапе сборки. Поскольку Amvera собирает
> проект из репозитория, держи прод-значения в **`.env.production`** (он
> коммитится; `.env` — локальный и в `.gitignore`).

## Уведомления

Сейчас уведомления складываются в общий стор и показываются в
колокольчике; для теста их можно добавлять вручную. Чтобы сделать
их «живыми», подключи WebSocket к сервису уведомлений: при входе
открой соединение, передай токен, и на каждое входящее сообщение
вызывай `useDesktopStore.getState().pushNotification({ app, text })`.
Удобное место для этого — `useEffect` в `Desktop.jsx`.

## Деплой на Amvera

1. Залей проект в Git-репозиторий (GitHub/GitLab или встроенный репозиторий
   Amvera).
2. В Amvera создай проект с окружением **Docker** и привяжи репозиторий.
   `docker-compose` там не нужен — достаточно `Dockerfile` (он в корне).
   Порт по умолчанию `80`, его менять не нужно.
3. Дождись сборки и привяжи домен с SSL (напр. `platform.ru`).
4. Каждое приложение — **отдельный проект** Amvera на своём поддомене
   (`siz.platform.ru` и т.д.). Один корневой домен + поддомены — это то,
   что делает единый вход безболезненным.

Обнови потом — просто `git push`.
